Technical Glossary

General Programming Terms

API General

Application Programming Interface. A set of rules and protocols that allows different software applications to communicate with each other. Think of it as a menu in a restaurant - it defines what you can order (request) and what you'll get in return.

Framework General

A pre-written collection of standardized code and tools that provides a foundation for developing software applications. Like a blueprint for building a house - it gives you the basic structure and tools to build upon.

JSON General

JavaScript Object Notation. A lightweight data format that's easy for humans to read and write and easy for machines to parse and generate. It's like writing a shopping list in a structured way that both humans and computers can understand.

Spring Framework Terms

Spring Boot Spring

An extension of the Spring Framework that simplifies the process of building production-ready applications. It provides defaults for code and annotation configuration to quickly get a Spring application up and running.

See also: Framework, Dependency Injection

Dependency Injection Spring

A design pattern where objects receive other objects that they depend on. Instead of creating an object inside a class, the object is created outside and "injected" into the class. It's like having a car factory that receives pre-made engines instead of building them from scratch.

Bean Spring

Objects that form the backbone of your application and are managed by the Spring IoC container. These are like the building blocks of your application that Spring takes care of creating and managing.

Database Terms

JPA Database

Java Persistence API. A specification for managing relational data in Java applications. It acts as a bridge between Java objects and database tables, making it easier to store and retrieve data.

See also: ORM, Entity

ORM Database

Object-Relational Mapping. A programming technique that lets you manipulate database data using object-oriented programming concepts. It's like having a translator that converts between your Java code and database operations.

Entity Database

A Java class that represents a table in your database. Each instance of the class represents a row in the table. Think of it as a digital form that matches the structure of your database table.

Security Terms

Authentication Security

The process of verifying who someone is. Like checking an ID card at the entrance of a building to confirm someone's identity.

Authorization Security

The process of determining what someone is allowed to do after they've been authenticated. Like checking what areas of a building someone has permission to enter after confirming their ID.

JWT Security

JSON Web Token. A compact, URL-safe means of representing claims between two parties. Like a digital passport that proves who you are and what you're allowed to do.

Web Development Terms

REST Web

Representational State Transfer. An architectural style for designing networked applications. It's like a set of rules for how web services should work together, similar to traffic rules for cars on a road.

HTTP Methods Web

Standard operations that can be performed on web resources:

  • GET: Retrieve data (like reading a book)
  • POST: Create new data (like adding a new book)
  • PUT: Update existing data (like updating book details)
  • DELETE: Remove data (like removing a book)

Thymeleaf Web

A modern server-side Java template engine for web applications. It allows you to create dynamic HTML pages by inserting data from your Java code. Like a smart word processor that can automatically fill in information in a document template.
