API Reference

Book Management API

The Book API provides endpoints for managing the library's book inventory. All endpoints require authentication unless specified otherwise.

List All Books

GET /api/books

Query Parameters

  • page (optional): Page number (default: 0)
  • size (optional): Items per page (default: 20)
  • sort (optional): Sort field (e.g., title,author)
// Response will appear here

Response Example

{
    "content": [
        {
            "id": 1,
            "title": "Spring Boot in Action",
            "author": "Craig Walls",
            "isbn": "978-1617292545",
            "available": true
        }
    ],
    "totalPages": 1,
    "totalElements": 1
}

Get Book Details

GET /api/books/{id}

Path Parameters

  • id: Book ID

Response Example

{
    "id": 1,
    "title": "Spring Boot in Action",
    "author": "Craig Walls",
    "isbn": "978-1617292545",
    "publisher": "Manning",
    "yearPublished": 2016,
    "available": true,
    "totalCopies": 3,
    "availableCopies": 2
}

Add New Book

POST /api/books

Request Body

{
    "title": "Spring Boot in Action",
    "author": "Craig Walls",
    "isbn": "978-1617292545",
    "publisher": "Manning",
    "yearPublished": 2016,
    "totalCopies": 3
}

Member Management API

The Member API handles library member information and operations. Administrative access is required for most endpoints.

Register New Member

POST /api/members

Request Body

{
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com",
    "address": "123 Library St",
    "phoneNumber": "555-0123"
}

Get Member Details

GET /api/members/{id}

Path Parameters

  • id: Member ID

Response Example

{
    "id": 1,
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com",
    "membershipStatus": "ACTIVE",
    "joinDate": "2024-03-09",
    "borrowedBooks": [
        {
            "bookId": 1,
            "title": "Spring Boot in Action",
            "dueDate": "2024-03-23"
        }
    ]
}

Lending API

The Lending API manages book borrowing and returns. Authentication and proper authorization are required.

Borrow Book

POST /api/lending/borrow

Request Body

{
    "memberId": 1,
    "bookId": 1,
    "borrowDate": "2024-03-09"
}

Return Book

POST /api/lending/return

Request Body

{
    "memberId": 1,
    "bookId": 1,
    "returnDate": "2024-03-23"
}

Authentication API

The Authentication API handles user authentication and authorization. These endpoints do not require prior authentication.

Login

POST /api/auth/login

Request Body

{
    "username": "librarian",
    "password": "secure_password"
}

Response Example

{
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "type": "Bearer",
    "expiresIn": 3600
}

Refresh Token

POST /api/auth/refresh

Request Headers

  • Authorization: Bearer {refresh_token}

Response Example

{
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "type": "Bearer",
    "expiresIn": 3600
}
