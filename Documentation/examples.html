Real Implementation Examples

Book Management Operations

Implementation Note:

The Book entity in our system is defined with the following fields:

  • bookId (Long): Unique identifier
  • name (String): Book title
  • author (String): Book author
  • genre (String): Book category
  • language (String): Book language

Scenario 1: Adding a New Book

Adding "Clean Code" by Robert C. Martin to the library system

API Endpoint: POST /books

// Request Body { "name": "Clean Code", "author": "Robert C. Martin", "genre": "Programming", "language": "English" } // Response (200 OK) { "bookId": 1, "name": "Clean Code", "author": "Robert C. Martin", "genre": "Programming", "language": "English" }

Implementation: BookController.addBook() method

Scenario 2: Retrieving Book Details

Getting information about a specific book

API Endpoint: GET /books/{id}

// Request: GET /books/1 // Response (200 OK) { "bookId": 1, "name": "Clean Code", "author": "Robert C. Martin", "genre": "Programming", "language": "English" }

Implementation: BookController.getBookById() method

Lending System Operations

Implementation Note:

The Lender entity manages book borrowing with these operations:

  • GET /lenders: List all lenders
  • GET /lenders/{id}: Get specific lender
  • POST /lenders: Register new lender
  • DELETE /lenders/{id}: Remove lender

Scenario 3: Registering a New Lender

Adding a new library member to the system

API Endpoint: POST /lenders

// Request Body { "name": "John Smith", "email": "john.smith@example.com", "membershipId": "LIB-2024-001" } // Response (200 OK) { "id": 1, "name": "John Smith", "email": "john.smith@example.com", "membershipId": "LIB-2024-001", "status": "ACTIVE" }

Implementation: LenderController.addLender() method

Implementation Details

Controller Structure

The system uses Spring REST Controllers with these key features:

  • @RestController annotation for REST endpoints
  • Constructor injection for services
  • Standard HTTP methods (GET, POST, PUT, DELETE)
  • ResponseEntity for proper HTTP responses
@RestController @RequestMapping("/books") public class BookController { private final BookService bookService; public BookController(BookService bookService) { this.bookService = bookService; } @GetMapping public ResponseEntity> getAllBooks() { return ResponseEntity.ok(bookService.getAllBooks()); } // ... other endpoints }

Entity Structure

Entities are mapped to database tables using JPA annotations:

@Entity @Table(name = "books") public class Book implements Serializable { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long bookId; private String name; private String author; private String genre; private String language; // ... getters and setters }
