Annotations Guide

Introduction to Annotations

Annotations are metadata that provide additional information about your code. They are like sticky notes that tell Spring and other frameworks how to handle your classes, methods, and fields.

Spring Framework Annotations

Component Annotations

Basic Usage
Advanced
Examples
@Component
public class EmailService {
    // Basic component
}

@Service
public class BookService {
    // Service component with business logic
}

@Repository
public class BookRepository {
    // Data access component
}

@Controller
public class BookController {
    // Web controller component
}
Best Practice:
  • Use @Service for business logic
  • Use @Repository for data access
  • Use @Controller/@RestController for web endpoints
  • Use @Component for general components
Common Pitfalls:
  • Don't mix @Controller and @RestController
  • Don't use @Component when a more specific annotation exists
  • Ensure components are in the correct scan path

Dependency Injection

@Service
public class BookService {
    private final BookRepository bookRepository;
    
    @Autowired // Constructor injection (preferred)
    public BookService(BookRepository bookRepository) {
        this.bookRepository = bookRepository;
    }
    
    @Autowired // Field injection (not recommended)
    private AuthorService authorService;
    
    @Autowired // Setter injection
    public void setPublisherService(PublisherService publisherService) {
        this.publisherService = publisherService;
    }
}
Best Practice:
  • Prefer constructor injection over field injection
  • Use final fields with constructor injection
  • Consider making @Autowired optional for non-required dependencies

JPA Annotations

Entity Mapping

@Entity
@Table(name = "books")
public class Book {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(name = "title", nullable = false)
    private String title;
    
    @ManyToOne
    @JoinColumn(name = "author_id")
    private Author author;
    
    @OneToMany(mappedBy = "book", cascade = CascadeType.ALL)
    private List reviews;
}

Validation Annotations

Common Validations

public class BookDTO {
    @NotNull(message = "Title is required")
    @Size(min = 1, max = 100)
    private String title;
    
    @NotBlank(message = "Author name is required")
    private String author;
    
    @Pattern(regexp = "^\\d{13}$", message = "ISBN must be 13 digits")
    private String isbn;
    
    @Min(0)
    @Max(1000)
    private Integer copies;
    
    @Email(message = "Invalid email format")
    private String contactEmail;
}
Validation Best Practices:
  • Always provide meaningful validation messages
  • Use appropriate validation constraints
  • Consider creating custom validation annotations for complex rules

Troubleshooting Guide

Common Issues

  • Component not found
    • Check component scanning configuration
    • Verify annotation is present
    • Check package structure
  • Circular dependency
    • Use constructor injection
    • Redesign component relationships
    • Consider using @Lazy
  • Validation not working
    • Add @Valid annotation
    • Enable validation in configuration
    • Check constraint annotations

Debugging Tips

  • Enable debug logging for Spring framework
  • Use Spring Boot Actuator for runtime information
  • Check component scanning with @ComponentScan
  • Verify annotation processor is enabled for Lombok
